# Canvas Drawing App Documentation

## Overview

This project is a browser-based drawing application built with the HTML5 Canvas API.
It supports:

* Smooth freehand drawing
* Zoom in / zoom out
* Camera panning
* Responsive canvas resizing
* Stroke smoothing using quadratic curves
* Redrawing saved strokes

The application uses:

* Native Canvas 2D API
* JavaScript event listeners
* A camera transformation system
* Stroke point storage

---

# Architecture

The app is divided into these main systems:

1. Global drawing state
2. Camera system
3. Drawing engine
4. Redraw engine
5. Mouse interaction system
6. Zoom & pan system
7. Resize observer

# GlobalState Object

```js
let GlobalState = {
  draw : false,
  points : [],
  oldx : 0,
  oldy : 0,
  sizeLine : 8,
  colorline : "#f81788",
  alpha : 0.2,
  allPoints : [],
  cursormode : false
}
```

## Properties

| Property       | Description                            |
| -------------- | -------------------------------------- |
| `draw`         | Indicates if user is currently drawing |
| `points`       | Current stroke points                  |
| `oldx`, `oldy` | Previous mouse coordinates             |
| `sizeLine`     | Stroke width                           |
| `colorline`    | Stroke color                           |
| `alpha`        | Smoothing factor                       |
| `allPoints`    | Stores all drawn strokes               |
| `cursormode`   | Indicates camera pan mode              |

# Drawing System

## Function

```js
function drawlines(xRaw, yRaw)
```

## Purpose

Draws smooth freehand strokes.

---

## Stroke Smoothing

The application smooths lines using interpolation:

```js
const x = oldx + (xRaw - oldx) * alpha
const y = oldy + (yRaw - oldy) * alpha
```

### Why?

Without smoothing:

* Lines appear shaky
* Mouse input looks rough

With smoothing:

* Curves become softer
* Drawing feels natural

---

## Quadratic Curves

The app uses:

```js
ctx.quadraticCurveTo()
```

instead of straight lines.

### Result

* Smooth brush strokes
* Better handwriting feel
* Reduced jagged edges

---

# Stroke Storage

Every point is saved:

```js
GlobalState.points.push({x,y})
```

At mouse release:

```js
GlobalState.allPoints.push(GlobalState.points)
```

This allows:

* Full redraw
* Zoom rendering
* Camera movement without losing drawings

---

# Redraw Engine

## Function

function redraw()

# Mouse Interaction System

---

## Left Mouse Button → Draw

### Event

```js
mousedown
```

When left click is detected:

```js
if(e.button == 0)
```

The app:

1. Converts screen coordinates to world coordinates
2. Starts a new stroke
3. Enables drawing mode

---

## Mouse Move → Continue Drawing

### Event

```js
mousemove
```

While drawing:

```js
if(GlobalState.draw)
```

The application continuously draws smooth curves.

---

## Mouse Up → Finish Stroke

### Event

```js
mouseup
```

Actions:

```js
GlobalState.draw = false
GlobalState.allPoints.push(GlobalState.points)
```

This finalizes the current stroke.

---

# Coordinate Conversion

## Problem

Canvas coordinates change when zooming/panning.

## Solution

Convert screen coordinates into world coordinates:

```js
((mouseX - Camera.x) / Camera.zoom)
```

This ensures drawing remains accurate under transformations.

---

# Camera Pan System

## Right Mouse Button

If user presses right-click:

```js
GlobalState.cursormode = true
```

The app enters camera drag mode.

---

## Panning Logic

Mouse movement delta:

```js
newDx = x - SaveOldest.x
newDy = y - SaveOldest.y
```

Camera position updates:

```js
Camera.x += newDx
Camera.y += newDy
```

Then:

```js
redraw()
```

is called to refresh the scene.

---

# Zoom System

## Zoom In

```js
Camera.zoom += 0.1
```

## Zoom Out

```js
Camera.zoom -= 0.1
```

After zooming:

1. Canvas clears
2. Transform reapplies
3. All strokes redraw

# Canvas Transform Matrix

The app uses:

```js
ctx.setTransform(a,b,c,d,e,f)
```

## Parameters

| Parameter | Meaning     |
| --------- | ----------- |
| `a`       | Scale X     |
| `b`       | Skew Y      |
| `c`       | Skew X      |
| `d`       | Scale Y     |
| `e`       | Translate X |
| `f`       | Translate Y |

Current usage:

```js
ctx.setTransform(
  Camera.zoom,
  0,
  0,
  Camera.zoom,
  Camera.x,
  Camera.y
)
```

# Performance Notes

Current redraw system redraws all strokes every frame.

This works well for small/medium drawings.

For large projects consider:

* Spatial partitioning
* Offscreen canvas
* Layer caching
* WebGL rendering
